# Python Datatypes Projects

This folder contains beginner-friendly Python projects created while learning **Variables**, **Data Types**, **Input/Output**, **Type Casting**, **Operators**, and **Basic Arithmetic**.

These projects are designed to strengthen Python fundamentals through simple practical programs.

---

# Projects Included

## 1. Age Calculator

Calculate age using the birth year and current year.

### Concepts Used

* Variables
* Integer data type
* User Input
* Type Casting
* Arithmetic Operators
* Formatted Output

---

## 2. EMI Calculator

Calculate monthly EMI, total payment, and total interest using the standard EMI formula.

### Concepts Used

* Variables
* Float data type
* Integer data type
* User Input
* Type Casting
* Arithmetic Operators
* Exponents
* Formula Implementation
* Formatted Output
