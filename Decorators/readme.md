# Python Decorators Projects

This folder contains Python projects created while learning **Decorators**, **Wrapper Functions**, **`*args`**, **`**kwargs`**, **Function Metadata**, **Logging**, and **Performance Monitoring**.

These projects demonstrate how decorators can be used to add additional functionality to existing functions without modifying their original logic.

---

# Projects Included

## 1. Application Logger

A logging decorator that automatically records function calls, arguments, return values, and exceptions.

The decorator is applied to a simple banking application to demonstrate how logging can be added to multiple methods.

### Features

* Log function calls
* Log function arguments
* Log returned values
* Log exceptions
* Save logs to a file
* Apply the same decorator to multiple methods

### Concepts Used

* Decorators
* Wrapper Functions
* `@wraps`
* `*args`
* `**kwargs`
* `logging`
* Exception Handling
* Classes and Methods
* File-based Logging

---

## 2. Performance Profiler

A timing decorator that measures and displays the execution time of functions.

The decorator is applied to different operations to demonstrate reusable performance monitoring.

### Features

* Measure function execution time
* Display function name
* Display execution time
* Reuse the decorator across multiple functions
* Test different types of operations

### Concepts Used

* Decorators
* Wrapper Functions
* `@wraps`
* `*args`
* `**kwargs`
* `time.perf_counter()`
* Function Execution Timing
* Performance Monitoring
