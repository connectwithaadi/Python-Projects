# Python List Projects

This folder contains beginner-friendly Python projects created while learning **Lists**, **Dictionaries**, **Functions**, **Loops**, **Object-Oriented Programming**, **File Handling**, and **JSON**.

These projects demonstrate the progression from a basic in-memory application to a more structured and persistent Python program.

---

# Projects Included

## 1. To-Do List

A simple command-line To-Do List application that allows users to add, view, complete, and delete tasks.

Each task is stored with its name and completion status.

### Features

* Add a task
* View all tasks
* Mark a task as completed
* Delete a task
* Exit the application

### Concepts Used

* Lists
* Dictionaries
* Functions
* `append()`
* `pop()`
* `enumerate()`
* Boolean Values
* `while` Loop
* Conditional Statements
* User Input
* Basic Input Validation

---

## 2. To-Do List V2

An improved version of the To-Do List application built using **Object-Oriented Programming** and **JSON file storage**.

Unlike the first version, tasks are saved to a JSON file and loaded when the program starts, allowing tasks to persist between program sessions.

### Features

* Add a task
* List all tasks
* Mark a task as completed
* Delete a task
* Save tasks to a JSON file
* Load saved tasks when the program starts
* Handle invalid task-number input
* Handle file-related errors

### Concepts Used

* Object-Oriented Programming
* Classes and Objects
* Methods
* Lists
* Dictionaries
* JSON
* File Handling
* `json.dump()`
* `json.load()`
* `os.path.exists()`
* Exception Handling
* `try` / `except`
* `enumerate()`
* `if __name__ == "__main__"`
* Docstrings
