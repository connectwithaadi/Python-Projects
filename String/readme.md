# Python String Projects

This folder contains beginner-friendly Python projects created while learning **Strings**, **String Methods**, **Loops**, **Conditional Statements**, and **Character Handling**.

These projects are designed to strengthen string manipulation skills and improve problem-solving through practical programs.

---

# Projects Included

## 1. Email Validator

Validate an email address using basic string checks and conditions.

The program checks for common issues such as missing `@`, invalid `@` placement, missing `.`, spaces, and an ending `.`.

### Concepts Used

* Strings
* User Input
* `.strip()`
* `.count()`
* `.startswith()`
* `.endswith()`
* `.split()`
* String Membership
* Conditional Statements
* Boolean Variables

---

## 2. Password Checker

Analyze a password and determine its strength based on length, uppercase letters, lowercase letters, digits, and special characters.

### Concepts Used

* Strings
* User Input
* `for` Loop
* `len()`
* `.isupper()`
* `.islower()`
* `.isdigit()`
* String Membership
* Boolean Variables
* Conditional Statements
* Password Strength Logic

---

## 3. Text Analyzer

Analyze a given text and calculate different text statistics.

The program counts characters, words, vowels, consonants, digits, spaces, uppercase letters, and lowercase letters.

### Concepts Used

* Strings
* User Input
* `len()`
* `.replace()`
* `.split()`
* `.lower()`
* `.isalpha()`
* `.isdigit()`
* `.isupper()`
* `.islower()`
* `for` Loop
* Conditional Statements
* Counter Variables
