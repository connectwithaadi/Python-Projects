# Python Functional Programming Projects

This folder contains Python projects created while learning **Functional Programming**, including **Lambda Functions**, **Map**, **Filter**, **Reduce**, **List Comprehension**, **Dictionary Comprehension**, and **Sorting with Key Functions**.

These concepts are practiced through a Student Result Analyzer that processes and analyzes student marks using different functional programming techniques.

---

# Projects Included

## 1. Student Result Analyzer

A Python program that analyzes student marks and generates useful results such as passed students, total marks, average marks, ranking, and grades.

The project demonstrates how functional programming techniques can be used to transform, filter, calculate, and sort data.

### Features

* Extract student names
* Convert student data into a dictionary
* Add bonus marks
* Filter passed students
* Calculate total marks
* Calculate average marks
* Generate student ranking
* Assign grades based on marks

### Concepts Used

* List Comprehension
* Dictionary Comprehension
* `map()`
* `filter()`
* `reduce()`
* `lambda`
* `sorted()`
* `enumerate()`
* Lists
* Dictionaries
* Conditional Expressions
