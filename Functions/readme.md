# Python Functions Projects

This folder contains beginner-friendly Python projects created while learning **Functions**, **Parameters**, **Return Values**, **Conditional Statements**, **Loops**, and **Menu-Driven Programs**.

These projects are designed to strengthen the understanding of functions by breaking larger programs into smaller and reusable pieces.

---

# Projects Included

## 1. Calculator

A menu-driven calculator that performs different mathematical operations using separate functions.

### Operations

* Addition
* Subtraction
* Multiplication
* Division
* Modulus
* Power
* Floor Division

### Concepts Used

* Functions
* Parameters
* Return Values
* Arithmetic Operators
* Conditional Statements
* `while` Loop
* User Input
* Menu-Driven Program
* Basic Error Handling

---

## 2. Banking Menu

A simple banking menu program that allows users to deposit money, withdraw money, and check their current balance.

### Features

* Deposit money
* Withdraw money
* Check balance
* Exit the program

### Concepts Used

* Functions
* Global Variables
* User Input
* Float Data Type
* Conditional Statements
* `while` Loop
* Menu-Driven Program
* Basic Input Validation

---

## 3. Employee Management System

A menu-driven employee management program that allows users to add, view, search, update, and delete employee records.

Employee records are stored using a list of dictionaries.

### Features

* Add Employee
* View Employees
* Search Employee
* Update Employee Salary
* Delete Employee
* Exit the program

### Concepts Used

* Functions
* Lists
* Dictionaries
* Loops
* Conditional Statements
* User Input
* Searching
* Updating Data
* Deleting Data
* Menu-Driven Program
