# Modern Python Projects

This folder contains practical Python projects created while learning modern Python features and writing cleaner, structured, and maintainable Python programs.

These projects focus on features such as **Dataclasses, Type Hints, Logging, Modern File Handling, Generator Expressions, and Object-Oriented Data Modeling**.

---

# Projects Included

## 1. Expense Tracker

A simple expense tracking program that organizes expenses by category, calculates total spending, generates an expense summary, and saves the report to a text file.

### Features

- Store expenses using a dataclass
- Categorize expenses
- Calculate total spending
- Generate category-wise expense summaries
- Display a formatted expense report
- Save the report to a text file
- Log important application events

### Concepts Used

- `@dataclass`
- Type Hints
- `List`
- `Path`
- `logging`
- Generator Expressions
- Dictionaries
- File Handling
- Formatted Output

---

## 2. Student Record Manager

A simple student record management program that stores student information, calculates subject averages, and assigns grades based on average marks.

### Features

- Store student records using a dataclass
- Store multiple subject marks
- Calculate student averages
- Assign grades based on average marks

### Concepts Used

- `@dataclass`
- Type Hints
- `List`
- Class Methods
- Mathematical Calculations
- Conditional Statements
- `logging`
- Formatted Output

# Learning Outcome

After completing these projects, you will understand:

- How to use `@dataclass` to create structured data models
- How type hints improve code readability
- How to use Python's `pathlib.Path` for file handling
- How logging can be used to track application activity
- How generator expressions can simplify calculations
- How dictionaries can be used to group and summarize data
- How methods can be used to organize data-related operations
- How modern Python features can make programs cleaner and easier to maintain
