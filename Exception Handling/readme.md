# Python Exception Handling Projects

This folder contains beginner-friendly Python projects created while learning **Exception Handling**, **Input Validation**, **Error Handling**, and **Robust Program Flow**.

These projects are designed to practice handling invalid inputs and unexpected situations without allowing the program to terminate unexpectedly.

---

# Projects Included

## 1. ATM System

A simple command-line ATM system that allows users to check their balance, deposit money, and withdraw money.

The program uses exception handling to validate transaction amounts and handle invalid menu input.

### Features

* Check account balance
* Deposit money
* Withdraw money
* Validate transaction amounts
* Handle insufficient balance
* Handle invalid menu input
* Continue running after input errors

### Concepts Used

* `try`
* `except`
* `else`
* `finally`
* `raise`
* `ValueError`
* Exception Objects
* User Input Validation
* Functions
* Global Variables
* `while` Loop
* Conditional Statements

## 2. Login System

A simple command-line login system that validates username and password input and limits the number of login attempts.

The program handles empty inputs, incorrect credentials, and successful authentication using exception handling.

### Features

* Username validation
* Password validation
* Maximum login attempts
* Incorrect username handling
* Incorrect password handling
* Successful login handling
* Graceful handling of invalid input

### Concepts Used

* `try`
* `except`
* `else`
* `finally`
* `raise`
* `ValueError`
* Generic Exceptions
* Exception Objects
* `.strip()`
* User Input Validation
* `while` Loop
* Conditional Statements
* Loop Control with `break`

# Learning Outcome

After completing these projects, you will understand:

* How to handle errors using `try` and `except`
* How to handle specific exception types
* How to raise exceptions using `raise`
* How to use `else` after successful execution
* How to use `finally` for code that should always execute
* How to validate user input
* How to prevent common input errors from crashing a program
* How to build more reliable command-line applications
* How exception handling can be combined with loops, functions, and conditions
