# Python OOP Concepts

This folder contains Python notebooks created while learning the fundamentals of **Object-Oriented Programming (OOP)**.

The notebooks cover the core OOP concepts step by step, starting from classes and objects and progressing to inheritance, polymorphism, encapsulation, and abstraction.

---

# Topics Included

## 1. Classes and Objects

### `001_Classes_objects.ipynb`

Introduction to the fundamental building blocks of Object-Oriented Programming.

### Concepts Covered

- Classes
- Objects
- Creating objects from classes
- Class attributes
- Object attributes
- Methods

## 2. Movie Project

A practical project created to apply Object-Oriented Programming concepts through a movie-related example.

### Concepts Covered

- Classes and Objects
- Attributes
- Methods
- Object creation
- Practical OOP implementation

## 3. Inheritance

### `003_Inheritance.ipynb`

This notebook focuses on inheritance and how classes can reuse properties and behavior from other classes.

### Concepts Covered

- Inheritance
- Parent class
- Child class
- Method inheritance
- Code reusability

---

## 4. Polymorphism

### `004_Polymorphism.ipynb`

This notebook focuses on polymorphism and how different classes can provide their own implementation of common behavior.

### Concepts Covered

- Polymorphism
- Method overriding
- Common interfaces
- Different behavior through the same method

---

## 5. Encapsulation

### `005_Encapsulation.ipynb`

This notebook focuses on encapsulation and controlling how data is accessed and modified inside classes.

### Concepts Covered

- Encapsulation
- Data protection
- Private attributes
- Controlled access to data
- Methods for accessing and modifying data

## 6. Abstraction

### `006_Abstraction.ipynb`

After completing these notebooks, you will understand:

- How classes and objects work in Python
- How to create and use objects
- How inheritance allows classes to reuse existing behavior
- How polymorphism allows different classes to implement common behavior
- How encapsulation helps control access to data
- How abstraction hides implementation details
- How the major principles of Object-Oriented Programming work together
- How OOP can be used to structure Python programs
